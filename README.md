# Merlin Operations Suite

Download Windows installers and verified update packages from [Releases](https://github.com/atelierzane/Merlin2026-Releases/releases/latest).

Merlin installs Administrator, Back Office, Point of Sale, Communicator, Polling Agent, and Onboarding Assistant together, with a shared launcher and update service.

- **Setup.exe** is the interactive installer.
- **MSI** is the per-machine installer for managed deployment.
- **INSTALL.md** explains workstation and SQL Server setup.
- **SHA256SUMS** lists checksums for the downloadable files.

The .NET runtime is bundled. Setup can install Visual C++ 2022 x64 and Edge WebView2 when needed. SQL Server is provisioned separately. See the installation guide included in each release for unattended and offline prerequisites.

This repository contains distribution assets and installation documentation. Application source is maintained privately.
